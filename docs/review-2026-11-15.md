### 1.1 HEAD 上的 4 个失败是什么

\`\`\`
FAILED tests/engines/test_llm_router_policy.py::test_nsfw_routes_a_live_local_server_to_the_local_model
FAILED tests/engines/test_llm_router_policy.py::test_complete_with_nsfw_policy_calls_the_local_model

**根因（已定位到行）**：HEAD 的 \`backend/app/engines/llm_router.py:652-654\` 把本地模型地址锁进模块级常量：

\`\`\`python
_LOCAL_LLM_URL = _settings.local_llm_base_url or os.environ.get("LOCAL_LLM_BASE_URL", "")
_LOCAL_LLM_KEY = _settings.local_llm_api_key or os.environ.get("LOCAL_LLM_API_KEY", "")
_LOCAL_LLM_MODEL = _settings.local_llm_model or os.environ.get("LOCAL_LLM_MODEL", "")
\`\`\`

而 \`local_route_available()\`（\`llm_router.py:741\`）在**调用时**重新取 \`narrator_factory.local_llm_reachable()\`。测试用 \`A._local_ready()\` 把 \`narrator_factory\` 的探针 patch 成永真，于是出现 **URL 常量说“没配”、探针说“可达”** 的分裂状态，\`local_route_available()\` 仍返回 \`False\` → \`with_content_policy()\` 返回 self → 断言 \`assert routed is not router\` 失败。

未提交的工作树把思路反过来（\`llm_router.py:658-672\`）：导入期常量只做兜底，运行时优先环境变量。

\`\`\`python
def _local_llm_url() -> str:
    return _settings.local_llm_base_url or os.environ.get("LOCAL_LLM_BASE_URL", "") or _LOCAL_LLM_URL
\`\`\`

**这是同一个 bug 的两次判决**：HEAD 的探针用“调用时”的值、可用性判断用“导入时”的值，两套事实来源必然打架。工作树的修法让两者统一，方向正确。

## 5. 值得肯定的设计（不要在这些地方“优化”）

这些是我读完全部核心代码后认为**应当保留并写进架构文档**的部分：

1. **确定性规则引擎**：\`rules_engine.py:920-929\` 用 \`sha256(campaign|turn|action|target)\` 播种 \`random.Random\`，\`:1039\` 战斗同种子 → 同一行动任何时候重放结果一致。这是“规则决定事实”的落地，很扎实。
2. **单一写入口 + 三层防护**：\`action_service\` 是唯一写路径；\`request_id\` 幂等（\`_replay\` :664）；\`commit_action\` 用 \`expected_version\` 做 CAS；状态 \`model_copy(deep=True)\`（\`:1063\`）避免原地污染。
3. **叙事失败不阻塞规则**：\`_degrade_story()\`（:791-816）让模型挂了也只降级文本，\`NarrativeResult.model='fallback'\` 前端有对应提示（\`GameCanvas.jsx:496-516\`）。这是“模型只负责叙事”的正确实现。
4. **保守修复**：\`state_diagnostics.py:264-369 repair_state\` 只做可证明安全的修复（未知位置→起点、负库存→0、未知引用→删），修复后保留原 \`updated_at\`（:367-368）。
5. **前端区分“规则拒绝”与“叙事失败”**：\`GameCanvas.jsx:479-536\` 对 \`rejected/conflict/duplicate\` 与 fallback 模型给出不同中文说明。
6. **快照裁剪策略**：\`SNAPSHOT_KEEP_RECENT=20 / KEEP_OLDEST=5 / KEEP_EVERY=10\`（\`game_state_store.py:47-54\`），且换过世界时整批保留（\`_history_belongs_to_another_world\` :566-592）——比“只留最近 N 个”聪明得多。
7. **启动器**：\`launch.py\` 的 \`is_our_page()\`（:134-151）判 \`id="root"\` + 项目标识、端口顺延、\`--no-window\` 看门狗、\`taskkill /T\` 杀进程树，工程质量高于一般个人项目。
